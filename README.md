
# Nyttige git operasjoner

- `git clone "https://github.com/oscar-kanskje/smarthus"` kopier dette git repositoret til pc-en din

- `git add` legg til endrede filer (kan bruke `git add *` for å legge til alle)
- `git commit -m 'beskrivelse av endringer'` bekreft endringer
- `git push` sett opp endringer på github
- `git pull` hent endringer fra github
